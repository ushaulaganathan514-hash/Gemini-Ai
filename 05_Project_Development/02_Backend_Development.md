# Backend Development

## Backend Technology

The EduGenie backend is developed using Python.

## Main Responsibilities

- Receive user questions
- Validate user input
- Process the request
- Communicate with the AI API
- Receive the AI response
- Send the response to the frontend

## Backend Flow

User Question
↓
Python Backend
↓
Input Validation
↓
AI API
↓
AI Response
↓
Frontend

## Error Handling

The backend should handle empty input, invalid requests, and API errors appropriately.

## Security

API keys should be stored in environment variables and should not be exposed in the source code or uploaded to GitHub.
