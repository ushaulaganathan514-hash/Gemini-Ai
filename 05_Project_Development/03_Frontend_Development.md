# Frontend Development

## Frontend Technologies

The EduGenie frontend is developed using HTML, CSS, and JavaScript.

## Main Components

- Project title
- Question input box
- Submit button
- Response display area
- Simple navigation

## User Interaction

1. User enters an academic question.
2. User clicks the Submit button.
3. The question is sent to the backend.
4. The AI-generated response is received.
5. The response is displayed on the screen.

## Design Goals

- Simple interface
- Easy navigation
- Clear and readable content
- Student-friendly design
- Responsive layout
