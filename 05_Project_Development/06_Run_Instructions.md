# Run Instructions

## Step 1 – Open the Project

Open the EduGenie-AI project folder in Visual Studio Code.

## Step 2 – Activate Virtual Environment

Activate the Python virtual environment before running the project.

## Step 3 – Install Dependencies

Install the required Python packages using the project's dependency file.

## Step 4 – Configure Environment Variables

Add the required AI API key to the `.env` file.

Do not share or upload the API key to GitHub.

## Step 5 – Run the Application

Run the Python application from the VS Code terminal.

## Step 6 – Open the Application

Open the local application URL in a web browser.

## Step 7 – Test

Enter an academic question and check whether EduGenie generates a response.
