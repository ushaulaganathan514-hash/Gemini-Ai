# System Architecture

## Overview

EduGenie is an AI-powered learning assistant that helps students understand academic topics through simple explanations and examples.

## System Flow

User
↓
EduGenie Web Interface
↓
Python Backend
↓
AI API
↓
AI Generated Response
↓
Response Displayed to User

## Main Components

### 1. User Interface
The user enters an academic question or topic.

### 2. Backend
The Python backend receives and processes the user request.

### 3. AI Integration
The system sends the request to an AI service for generating the answer.

### 4. Response
The generated explanation is returned and displayed to the user.

- Python
