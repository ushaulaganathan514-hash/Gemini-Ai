# Data Flow

## User Input

The user enters an academic question or topic in the EduGenie interface.

## Request Processing

The request is sent from the web interface to the Python backend.

## AI Processing

The backend sends the user's question to the AI API for processing.

## Response Generation

The AI service generates a simple and understandable answer.

## Response Display

The generated answer is returned to the backend and displayed to the user.

## Data Flow

User Input
↓
Web Interface
↓
Python Backend
↓
AI API
↓
Generated Response
↓
User
