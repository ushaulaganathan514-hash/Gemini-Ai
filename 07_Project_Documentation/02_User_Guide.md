# User Guide

## How to Use EduGenie

### Step 1
Open the EduGenie application in a web browser.

### Step 2
Enter an academic question or topic in the input box.

### Step 3
Click the Submit button.

### Step 4
Wait for the AI to process the question.

### Step 5
Read the generated explanation displayed on the screen.

## Tips

- Enter a clear question.
- Use specific academic topics.
- Check the generated explanation carefully.
- Do not enter private or sensitive information.

## Error Handling

If an error occurs, check the internet connection and try again.
